# CashX Ecosystem NFT Mint

First-pass launch site and contract draft for a 10,000-piece CashX Ecosystem NFT collection on PulseChain.

The website currently runs as a safe preview: it shows the confirmed collection structure and mint experience but does not connect wallets or request funds until the final contract and treasury details are supplied.

## Local development

```bash
pnpm install
pnpm dev
```

## Production check

```bash
pnpm build
```

Read `PROJECT-BRIEF.md` before enabling any wallet or mint transaction.
